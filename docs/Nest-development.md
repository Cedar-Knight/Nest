## 目标与边界｜已确定

### 要解决的问题

- 根据室内工蚁活动，找到隐蔽且实际使用的进入或离开位置。
- 输出入口候选位置、对应观测证据、规则确认或未确认状态。
- 工蚁出入口不一定是实际巢穴入口；不假设室内所有工蚁来自同一巢穴。
- 研究重点：母巢集中分析，子机离线采集并返巢交接，分析结果影响下一轮任务。
- 完整系统扩展至确认入口后的定点处理；目前先验证发现与复核闭环。

### 首版运行范围

- 仅地面移动；目标限定为能从地面接近、观察的入口。
- 优先缩小子机体积；每台侦察机仅一个摄像头。
- 离巢时采集并保存数据，返巢后上传；不依赖无线数据传输。
- 用户目前无法开展实物实验；现阶段采用公开研究、规格核查和离线计算。
- 该替代路径能减少未知，不能完成本项目实物验收。

## 两个实现范围｜已确定

### 目前实现

- 配置：母巢＋1台标准侦察子机＋上传底座；母巢计算暂用已有电脑。
- 流程：下发采集任务 → 离巢记录 → 返巢上传 → 母巢分析 → 再次出发定点复核 → 回传结果。
- 范围：入口发现、证据定位与复核；暂不实现第二台侦察机和滴药封口。
- 完成标准：一次可检查、可复查的发现与复核闭环。
- 第一台按完整系统的标准侦察模块设计，后续直接复制第二台。

### 完整实现

- 配置：1个母巢＋2台相同侦察子机＋1台处理子机。
- 两台侦察机分区并行采集；母巢分析后安排候选入口共同复核。
- 共同复核是任务安排，可分轮次进行，不要求离巢期间实时协调。
- 流程：并行采集 → 返巢交接 → 母巢分析建图 → 派发复核 → 规则确认 → 派发处理 → 处理记录回传及效果复查。
- 完成标准：多机搜索、入口复核和处理形成闭环；药剂与封口条件须先明确。
- 多机收益需与单机在可比总时间、路径或能耗预算下比较，不能由数量推定。

## 母巢与子机职责｜已确定

### 母巢

- 保存并合并各轮、各机上传的记录。
- 在记录中识别蚂蚁、分析单只蚂蚁轨迹与进出事件。
- 根据视频与运动数据，分轮次更新空间地图和定位估计。
- 管理候选入口、合并重复位置、复核证据、执行计数规则。
- 决定搜索区域、路线、观察点、观察时长、返航条件和下一轮任务。
- 完整系统中负责多机分配及处理决策。
- 无离巢通信时，不能实时分析最新画面、控制追蚁或替子机纠偏。

### 标准侦察子机

- 两台硬件、基础软件与能力相同；仅编号、任务及参数可能不同。
- 接收并执行母巢任务，记录带时间信息的视频和运动数据。
- 本地完成必要的电机闭环、障碍停车、返航纠偏和对接执行。
- 保存数据直到母巢完成接收；高层蚂蚁识别、地图合并和任务决策归母巢。
- 单只蚂蚁是母巢分析的跟踪对象，不是首版子机实时追逐的控制目标。
- 本地返航执行必须有反馈；简单倒放电机动作不能等同于可靠原路返回。

### 处理子机

- 接收母巢给出的已确认位置及处理任务。
- 执行接近、滴液、施胶及操作结果记录。
- 处理模块与侦察模块职责分开；具体底盘复用方式尚未确定。
- 不自行决定药剂、用量、封口时机或目标是否可处理。

## 运行流程与交接

### 搜索轮

- 母巢分配区域和采集任务；双机时初始分区并行。
- 子机按任务采集视频及运动记录，按返航条件返回。
- 在底座通过接触式／USB接口上传；不另配无线数据传输器。
- 母巢对齐视频和运动时间，更新地图与候选入口。
- 发现候选点后，把定点复核任务写入下一轮任务。

### 复核轮

- 子机抵达候选点并稳定观察，最多记录3分钟。
- 返巢上传，母巢检查实际进入／离开事件及位置关联。
- 结果不足或图像无效，输出未确认或数据不足，不能强行触发处理。
- 双机对同一入口形成的重复证据由母巢合并，不重复累计同一事件。

### 开发接口草案｜待落实字段与协议

- 母巢 → 子机：任务编号、子机编号、任务类型、区域／目标点、动作与观察参数、返航条件。
- 子机 → 母巢：任务记录、时间基准、视频、编码器／IMU记录、测距与执行状态、异常信息。
- 母巢输出：地图版本、候选入口编号／位置、证据片段、事件时间与方向、计数、判定结果。
- 底座交接：到位检测 → 建立连接 → 上传校验 → 接收确认 → 下一轮任务交接。
- 上传失败时保留原记录；具体重试次数、存储管理与任务状态机尚待开发定义。

## 入口判断规则 v0｜已确定，参数暂定

### 固定规则

- 对同一候选物理入口，进入或离开合计 **5次**。
- 从有效观察开始计时，最多 **3分钟／180秒**。
- 计数单位是出入事件，不是帧数，也不要求5只不同蚂蚁。
- 达到门槛输出“规则确认”；超时不足输出“未确认”。
- 未确认不表示没有入口；规则确认也不证明入口直达蚁巢。
- 普通过路、停留、目标检测丢失和遮挡消失均不能直接算一次进入。
- 跨摄像头重复事件应去重；失去同步时不能声称已准确合并。
- 验证用真实入口标签须独立标注或复查，不能用5次规则生成自己的真值。

### 后续动态阈值｜未采用

- 用户提出以母巢记录的单位时间活动数量乘以系数 n 调整门槛。
- 需确定参考区域、历史时间窗、系数 n、观察时长和零活动时的处理。
- 若参考量为速率 r，可研究 `K = ceil(n × r × T)`，双方以事件次数比较。
- 参考统计不能直接使用本轮计数 C，否则比较 C 与 n×C 没有有效区分意义。
- 当前仍执行固定5次／3分钟规则。

## 侦察硬件与观测｜暂定工程基线

### 成像与记录

- Raspberry Pi Zero 2 W＋Camera Module 3 Wide＋存储卡。
- 单摄像头配一轴俯仰，分别承担环境记录与入口近距离观察。
- 首版视频目标：1080p、30帧／秒，压缩后本地保存。
- Wide镜头官方最近调焦距离5cm、水平视角102°。
- 暂定近距离观察：镜头中心离地4cm，目标斜距5.5–6cm，向下俯仰约42–47°。
- 暂定工程目标：体长至少约3.5mm的蚂蚁；更小目标尚无成像保证。
- 理想几何估计约30–50像素体长，受方向影响；不等于已经证明能识别或跟踪。
- 实际视频裁切、畸变、模糊、光照和遮挡需要另行检验；切换焦距／俯仰后需校准。
- 廉价ESP32摄像方案暂不作为等性能替代：近距离成像与持续录制能力未核实。
- 板载无线功能可以不使用；不用无线传输并不会自动消除板载无线硬件成本。

### 运动与传感

- 两轮差速底盘，两个150∶1、6V、105 RPM带编码器微型减速电机。
- 独立底层运动控制器和双路驱动；编码器用于运动反馈。
- IMU辅助运动估计，前方ToF用于近障测距；单个ToF不能直接当作完整建图雷达。
- 一轴微型舵机调整摄像头俯仰。
- 电池、稳压与保护预算已计入，但电压分配、峰值电流、续航尚未完成设计核查。
- 返航定位、地图表示、避障覆盖与自动对接方案仍需收敛。

### 体积

- 优先小型化，尚无确定的整机尺寸上限。
- 先前约10×7×6cm只是空间估计；没有CAD、装配或重量证据，不作为尺寸承诺。
- 完成器件布局、线缆、轮距与电池设计后再给正式外形尺寸。

## 滴药与封口｜完整实现的构想

- 用户方案：滴管滴入液体蚂蚁药，再施加会固化的胶封口。
- 未选定具体药剂和胶；用量、材料相容性、固化时间与机构均未确定。
- 滴药后是否可立即封口尚未确定，不能把动作顺序直接当作有效处理流程。
- 处理前需确定入口位置、可接近性、滴注／点胶精度与允许处理条件。
- 处理成功需有后续观测依据，不能用“机构已执行”推定蚂蚁已清除。
- 目前实现不开展该模块；完整系统的处理费用尚不能定价。

## 证据与验收边界

### 已有证据

- [公开研究与数据复算](research/Nest_ant_entry_evidence_2026-10-05.md)：15份已知野外活动入口人工事件记录，均在8–37秒达到5次；排除一份后续时间回退记录后，14份仍全部达到。
- 该结果仅支持已知活动入口的门槛可达性，不能给出室内误报、视觉漏检或机器人定位精度。
- [Camera Module 3官方规格](https://datasheets.raspberrypi.com/camera/camera-module-3-product-brief.pdf)：镜头、尺寸与调焦依据。
- [Zero 2 W官方规格](https://www.raspberrypi.com/products/raspberry-pi-zero-2-w/)：采集平台接口与编码能力依据。
- [相机官方价格说明](https://www.raspberrypi.com/news/new-autofocus-camera-modules/)：Wide标价35美元。
- [150∶1电机规格与标价](https://www.dfrobot.com/product-1434.html)：单个11.90美元；查询时缺货，采购时需复查。
- [DRV8835驱动规格](https://www.pololu.com/product/2135)：双路驱动候选，支持3.3V控制；仍需核对电机峰值电流。

### 目前实现的验收

- 记录有效：视频、运动信息与任务编号可关联，时间信息足以定位事件。
- 交接有效：返巢后文件完整接收，母巢能从记录定位候选入口及证据片段。
- 决策有效：下一轮任务确实依据上一轮结果生成，子机完成定点复核记录。
- 判定可复查：展示180秒内的事件清单、去重依据和规则输出。
- 闭环可追溯：每次失败能区分成像、检测、定位、返航、对接和上传问题。
- 一次闭环是初步完成标准，不等于稳定性达标；可靠性指标需重复试验。

### 完整实现的追加验收

- 两台同型机能接受同类或不同任务；母巢能合并各轮数据并协调复核。
- 与单机比较入口发现时间、覆盖、重复采集、路径／能耗及失败次数。
- 明确记录定位误差、返航成功率、对接成功率、上传完整率和失败原因。
- 对入口判定报告独立真值下的误报与漏检，不能只统计门槛触发数量。
- 处理机完成位置执行与剂量／点胶验证，再复查实际处理效果。
- 具体通过阈值、重复次数和试验场地尚未定，正式验收前需补齐。

## 开发前仍需收敛的事项

- 关键结构条件：离线母巢规划与子机本地返航执行如何衔接，首轮无完整地图时怎样安全返回。
- 观测条件：实际相机视频视野、近／远成像、光照与可识别目标范围。
- 定位条件：地图表示、运动误差累计、到候选点的定位精度及返航纠偏。
- 机械条件：器件布局、总重、地面通行、镜头姿态及底座导向。
- 电气条件：电池规格、各电压支路、电机／舵机峰值和稳定录制供电。
- 交接条件：自动对准、接触式USB信号质量、到位检测与断连恢复。
- 验收条件：指标阈值、试验真值与重复次数；公开资料无法代替这些实物结果。
- 处理条件：药剂、胶、剂量、时序和处理机构；可留至完整实现阶段。
