# 架构草案

当前范围以[Nest开发定义](Nest-development.md)为准。下列目录是待实现的模块边界，不是已经验证的系统。

| 模块 | 责任与输入 | 输出与边界 |
| --- | --- | --- |
| mission | 母巢任务生命周期、上一轮有效结果 | 带来源的采集／复核任务；无有效位置不派发可执行定点任务 |
| transport | 返巢记录清单、文件与校验值 | 完整接收凭据；失败保留源记录，重复接收不重复执行 |
| perception | 视频／人工事件、时间基准 | 进出事件及证据引用；遮挡消失不等于进入 |
| localization | 编码器、IMU、场地观测、地图版本 | 带坐标系与误差说明的位置；首轮定位与返航方案尚未定 |
| mother | 有效记录、事件、位置和候选入口 | 合并与分析，生成下一轮任务；无离巢实时控制 |
| scout | 离巢前任务与本地传感 | 运动、停车、返航执行及记录；须有本地反馈 |
| evaluation | 独立真值、运行结果与资源消耗 | 可复查指标与失败分析；样例不证明实物性能 |

依赖：P1先用本地文件和人工样例验证交接，定位和视觉适配器显式标注为人工／模拟；P2收敛实物设计，P3建立观测分析基线，再在条件具备时做P4实物集成。

模块之间的数据草案见[接口](interfaces.md)，首任务见[P1](tasks/P1-offline-handoff.md)。暂不引入数据库、消息中间件、云服务或额外框架。实际依赖随任务选择并记录理由。

首版不实现处理机。后续处理模块只有定位、复核、具体材料与动作条件通过后才进入开发；暂不建立虚假的处理执行代码。
