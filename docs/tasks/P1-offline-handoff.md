# P1：离线任务交接与复核派发

状态：Planned，P0计划待负责人审阅。本任务不是实现整个机器人系统。

目标：母巢下发采集任务，用样例模拟子机返回记录，完整接收后依据记录中的人工候选生成复核任务，再将复核结果关联原候选。

## 交付

- 明确的任务／返回记录／接收凭据与失败状态，接口草案见[interfaces](../interfaces.md)。
- 可以在普通电脑重跑的本地文件夹交接入口；无硬件、无自动视觉或定位假设。
- 正常与异常检查及日志；所有人工／模拟适配器标注来源。

## 验收

1. 完整文件校验、接收确认通过后，才生成一个来源可追溯的定点复核任务。
2. 缺文件、校验失败和中断不提前确认，子机源记录保留；重试可恢复。
3. 重复上传不重复创建任务；相同编号内容不同明确报冲突。
4. 位置、时间或观测不足时明确返回数据不足或人工检查；不伪造复核目标。
5. 人工事件清单按实际进出事件判断5次／180秒；展示证据、计数与输出，复核结果关联正确候选。

## 分工与边界

负责人判断“什么时候算完整接收”和“证据不足后做什么”；贡献者可实现支持代码、样例与检查。先用两个90分钟工作段，之后重估。

主要学习检查：解释一次交接的状态变化，预测复制中断后的重试行为，再换一个中断点核查。实现通过和学习通过分别记录。

通过后更新[项目导图](../Nest-development.md)与证据路径。不得将P1完成写成真实入口识别、定位、返航、对接或供电已通过。
